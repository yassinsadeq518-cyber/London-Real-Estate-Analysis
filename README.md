# London-Real-Estate-Analysis
# 🏠 London Real Estate Market Performance Analysis (2019-2024)

## 📌 Project Overview
A 5-year comprehensive real estate analytics project that tracks property listings, pricing dynamics, and market trends across various London boroughs and districts.

## 📊 Key Insights & Features
* **Pricing Benchmarks:** Analyzed the average price per size (£2,788.73) across property types including Apartments, Houses, and Penthouses.
* **Geographic Analysis:** Identified premium pricing zones, with high-end locations like Bishops Avenue leading the property value indexes.
* **Market Status Mapping:** Visualized update reasons (price reductions vs. fresh listings) categorized across property size brackets.

## 🛠️ Tech Stack & Skills
* **Tool:** Power BI Desktop
* **Data Processing:** Managing large-scale structural real estate datasets, removing anomalies, and standardizing regional attributes.
* **UI/UX Design:** Implementing clean, executive-level navigation suitable for real estate investors.
